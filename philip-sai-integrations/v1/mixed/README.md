# Mixed lane

Scenarios where Sai and the owner (or Phillip) both contribute to the same paper or
workflow — for example, Sai selects the paper and the owner extends the workload or
adds binding fixtures.

Set `source_lane: "mixed"` and list every contributor in `manifest.json`. Register the
scenario in `philip-sai-integrations/v1/catalog.json` with all contributor IDs.
