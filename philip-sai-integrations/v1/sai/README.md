# Sai lane

Sai-owned integration scenarios: papers and Proto workflows he selects independently.

Copy `philip-sai-integrations/v1/sai/_template/` to a new `<scenario_id>/` directory,
fill in `manifest.json` and `methodology.json`, then register the scenario in
`philip-sai-integrations/v1/catalog.json`.

Use `status: "draft"` while iterating; set `"active"` once the scenario is ready for
shared ranking and ProtoStage analysis.
