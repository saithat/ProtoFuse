# ProtoFuse hosted evaluation dashboard

Single-page readout of the repository's current trace coverage, surrogate training status,
held-out cohorts, and full-versus-fused benchmark evidence.

This React application is an optional hosted presentation. Its current ChatGPT Sites URL
can be access-controlled and should not be treated as the portable report. For sharing with
anyone who has a clone or for archiving alongside results, use the self-contained
`reports/protofuse-evaluation.html` generated by `scripts/build_evaluation_report.py`.

The displayed values are a reviewed snapshot of local analysis artifacts recorded on
2026-08-15. Missing comparisons are intentionally labeled `not run`; they are not zeros.
The training section explains why proposal rows from one seeded optimizer trajectory remain one
split group, shows the current 6/2/2-trajectory pilot split, and distinguishes it from the planned
60/20/20 train/calibration/test collection.

```bash
npm ci
npm run dev
npm run build
npm test
```
